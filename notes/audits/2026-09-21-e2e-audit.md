## Notable P2s (filed)

- **Security: AUTH_PASSWORD throttle fails OPEN when KV unset** — 8 straight
  wrong passwords, no throttle; `FAIL_CLOSED_ON_SHIM` covers only MINT_INVITE
  + PLACES. (#141/#139 family.)
- **Invite Copy-link failure = dead end** — clipboard denial mis-reported as
  `ERRORS.network`; full invite URL is rendered nowhere (only truncated
  token), so the organizer has no manual path. Front door of the product.
- **Blank display name publishes email local-part** — `handle_new_user`
  falls back to `split_part(email,'@',1)`; skipping the optional name field
  on invite-accept discloses an email fragment to the whole crew.
- **State B rendered for accounts whose password was set out-of-band**
  (`has_password` shadow col false) — new password settable with no
  current-password challenge; State-C link absent. Self-heals only on in-app
  password sign-in.
- **RSVP chips can lock up disabled after a change** (1/4 runs under load;
  `useTransition` pending never resolves; no error surface, no retry path).
- **Revoked invite row keeps a working "Copy link" until reload** (UI stale
  after revoke; see also #563 comment — revoked/expired/exhausted are
  indistinguishable *by construction*: revoke = `expires_at = now`).
- **Add-item form lacks the #634 fields** (location, notes are edit-only →
  create-then-edit round trip).
- **Organizer cannot close/edit/delete any poll** — RLS policies exist, UI
  affordance doesn't; a typo'd poll is immortal.
- **Celebrant date-poll marks re-sort the list under the finger** — second
  tap in the same spot vetoes a different window (happened to the auditor).
- **member email+phone serialized into the RSC payload for every viewer**
  (#596 is broader than filed; email latent-only today — no code writes
  `trip_members.email` yet). See #596 comment.
